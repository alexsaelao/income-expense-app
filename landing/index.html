FAQ

Questions people ask

Keep answers short so the landing page stays focused on conversion.

Does the app work offline?

Yes. Wallet Code Sabai is built as an offline-first PWA, so it stays usable even when the network is weak or unavailable.

What does Pro unlock?

Pro is meant for cloud sync, cross-device restore, and a smoother upgrade path through redeem code or entitlement.

Can I export my data?

Yes. JSON is the backup format for restore, while CSV is better for spreadsheet analysis and sharing with other tools.

Is this landing separate from the app?

Yes. This folder is intentionally separate so the promo site can evolve without touching the main finance app UI.
